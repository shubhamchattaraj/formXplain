# Devpost submission checklist (to complete honestly)

- [ ] Read current official rules and submission questions.
- [ ] Install official Learn Skill Pack and inspect actual skill instructions.
- [ ] Complete `1-start` → `2-scope` → `3-prd` → `4-spec` → `5-build` → `6-ship` in order.
- [ ] Review/update scope, PRD, and spec based on real project decisions.
- [ ] Complete and record browser tests for text PDF, scanned PDF, mixed PDF, PNG/JPEG, errors, search, source pages, checklist, print/export, navigation, mobile, and reset.
- [ ] Review third-party dependency licenses and CDN availability.
- [ ] Check repository history and working tree for secrets and private documents.
- [ ] Publish public repository with open-source license.
- [ ] Record and publish a demo video shorter than three minutes.
- [ ] Complete project description and all current Devpost submission fields.
- [ ] Describe actual Skill Pack use and known limitations accurately.
