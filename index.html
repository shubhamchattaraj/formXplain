CONTROL & TRANSPARENCY

Settings & privacy

Understand how this prototype handles documents and what it can — and cannot — do.

Processing mode

PDF text extraction and OCR run in the browser. When the server has a Gemini API key configured, extracted document text is sent to Google Gemini to generate the summary. Otherwise, a labelled local fallback is used.

Local demo
Data retention

Document text and checklist state live in memory for this page session. They are not intentionally persisted to localStorage or sent to a formXplain backend. Third-party CDN requests occur to load libraries, fonts, and OCR language data.

Session only
Clear current document

Remove the active document, extracted text, requirements, and checklist from the current session.

Known limitations

OCR can misread numbers, tables, handwriting, stamps, and checkboxes. Local summaries and requirement detection are heuristic. Search results are not generated answers. Official deadlines and eligibility are not independently verified.
